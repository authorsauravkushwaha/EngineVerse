Install {{ brand.site_name }} on your phone

It is a progressive web app: no app store, no download size to speak of, works offline, and it lives on your home screen like any other app.

Android (Chrome)

  1. Open this site in Chrome.
  2. Tap the ⋮ menu, then Add to Home screen or Install app.
  3. Confirm. The icon appears on your home screen.

iPhone (Safari)

  1. Open this site in Safari — Chrome on iOS cannot install web apps.
  2. Tap the Share button.
  3. Choose Add to Home Screen.

Desktop

  1. Look for the install icon in the address bar, or
  2. Use your browser menu → Install {{ brand.site_name }}.
